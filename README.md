## 📜 О проекте (About)

В эпоху глобальной цифровизации традиционные нейронные сети (MLP, CNN, RNN) сталкиваются с ограничениями масштабируемости и устойчивости к шуму. **Sfiral Engine** предлагает решение через новую архитектуру, вдохновленную природными процессами и геометрией сфирали.

Система объединяет два ядра в едином "Двухъядерном Двигателе" (Dual Core):

1.  **🧬 LOGOS (Семантическое Ядро):**
    Отвечает за работу со смыслами (Лингвистика). Использует **S-Логику** для синтеза новых понятий через напряжение между Тезисом и Антитезисом.
    *Пример:* `ХАОС` + `ПОРЯДОК` → `ГАРМОНИЯ`.

2.  **🧠 NEUROCORTEX (Фрактальное Ядро FSIN):**
    Отвечает за математическую обработку сигналов. Реализует модель **Фрактального Сфирального Нейрона**, способного гасить шум и выявлять аномалии с высокой точностью.

> *"Технология ФСИН символизирует гармонию и баланс, объединяя современные технологии с культурными символами."* — [Басаргин О.С., 2025]

## 🏗 Теоретическая база и Архитектура

### 1. Принцип Зеркальной Антисимметрии
В отличие от классических нейронов, Сфиральный Нейрон обрабатывает данные в двух параллельных каналах с противоположными характеристиками. Это позволяет взаимокомпенсировать ошибки и выделять чистый сигнал.

**Математическая модель:**
$$Output = f(W_1 \cdot x) + (-f(W_2 \cdot x))$$
Где один канал работает на возбуждение ($V+$), а второй — зеркально на торможение ($V-$).

### 2. Фрактальная Структура
Архитектура строится по принципу самоподобие. Каждый слой сети повторяет структуру целого, но в меньшем масштабе. Это обеспечивает:
* **Масштабируемость:** Адаптация к задачам любой сложности.
* **Энергоэффективность:** Распределение нагрузки между уровнями фрактала.

### 3. S-образная Интеграция
Модуль интеграции объединяет потоки данных, учитывая временные задержки и пространственные зависимости (Вращение в S-пространстве).

## 🚀 Установка и Запуск (Installation)

### Предварительные требования
* Python 3.8 или выше
* Библиотеки: `torch`, `numpy`, `pandas`, `streamlit`

### Пошаговая инструкция

1.  **Клонирование репозитория:**
    ```bash
    git clone [https://github.com/Sfiralium/Sfiral-Engine.git](https://github.com/Sfiralium/Sfiral-Engine.git)
    cd Sfiral-Engine
    ```

2.  **Установка зависимостей:**
    ```bash
    pip install torch numpy pandas streamlit
    ```

3.  **Запуск Центра Управления (Web Interface):**
    ```bash
    streamlit run app.py
    ```

После запуска откройте браузер по адресу: `http://localhost:8501`.
